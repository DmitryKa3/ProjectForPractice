# Практика2курс
Учебный проект на C# с использованием Windows Forms и SQLite. 
- Приложение предназначено для хранения информации о товарах и предоставляет базовый функционал для работы с базой данных: просмотр, добавление, редактирование и удаление записей.

# Функционал
Отображение, добавление, удаление, редактирование товаров.

# Используемые технологии

- C# (.NET Framework)
- Windows Forms
- SQLite (Используется удобства и простой установки приложения.)

# Как запустить?

Скачайте архив из [релизов](https://github.com/DmitryKa3/ProjectForPractice/releases/tag/Tag) и запустите .exe файл.
